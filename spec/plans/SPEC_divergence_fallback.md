# SPEC：进场背驰「下沉链回退 + 段去重重置」（M1/M2，近等双底二底可进场）

> 状态：**已实现（2026-09-11）**。触发案例与全量回测对比见文末「实施结果」。
> 修改对象：`py_chain/mark_entry.py`（当下制 realtimeLowerDiverge / _sinkChainRealtimeNodes）、
> `py_chain/backtest.py`（_rearm_fired）、`py_chain/chan_core.py`（CHAN_CFG 开关）。
> JS 侧 **无对应改动**：mark-entry SKILL 仅实现确认制（sinkChainConfirm/lowerDiverge），
> 当下制只存在于 py 引擎——本规则为引擎侧扩展，确认制不受影响。

## Context：8-7 08:45 案例（XAUUSD）

1 小时下跌笔（8-6 10:00 4304.31 → 8-7 08:45 4229.875，近等双底取后底）内部的 15m
二底 4229.875：较前底 4223.505（8-7 00:15 插针）仅高 0.37，MACD 动能全面衰竭
（绿柱面积 0.6 vs 50.8、DIF 低点 -2.02 vs -6.69、绿柱峰值 0.6 vs 7.2），但系统三道拦截：

1. **15m 未创新低**（4229.875 > 4223.505）→ 不构成底背驰候选（背驰要求创新低）；
2. **15m 计划 wait2Buy 的结构条件**（上涨段过前高 4284.885 < 4304.31、MACD 上 0 轴）未过；
3. **X=60 关键路径**：区间套下沉 60→15→3（3m 在 15m 段内展开 ≥3 笔），候选**只在停止级 3m 产出**：
   3m 末段创新低成立但动能加速（绿柱面积 36.2 vs 7.5）→ isBiDiverge=False → 无信号。
   **15m 级真背驰被跳过**——引擎口径 15m 形成段（17:15→23:45，4229.51）vs 参照
   （10:00→13:30，4247.24）：严格创新低 ✓ + isBiDiverge ✓。

另：首笔信号（8-6 21:00 X=60/waitBuy/mark=15/segStart=17:15）的去重键与回退候选完全相同，
即使回退产出候选也会被段去重吞掉 → 需配套重置规则。

## 规则

### M1 下沉链回退（CHAN_CFG.sinkFallback，默认开）

- `realtimeLowerDiverge` 评估顺序由「只评停止级 S」改为「S 优先，S 无候选（段方向/
  创新低/背驰任一不过）时沿下沉链向上一级重评」，回退级别仍须**严格低于检测周期 X**；
- 每级评估用该级**形成中段**（引擎已延伸到当下极值）vs 该级「最近同向已完成参照笔」，
  参照的 span≥50% 跳过与规则 2（参照须在上级容器内）约束不变——容器取该级在链中的
  parentBi（`_sinkChainRealtimeNodes` 逐级记录）；
- 非停止级命中的候选带 `fallback=True`（信号与成交全程透传，webapp 表格可见）；
- SPEC_divergence_chanset 规则 3 相应修订：markRes = 停止级优先；停止级无候选时取
  **回退首个命中级**（仍 < X）。

### M1 配套段去重重置（CHAN_CFG.sinkFallbackRearm，默认开）

- 同向持仓**终局**（close/stopSr/stopBe）后，重置该 `(periodX, strategyKey, markRes)`
  三元组的全部 `_rt_fired` 键——同一形成段允许在上一单终局后**再发一次**信号；
- 同向互斥持仓期间不重置；不加止损冷却（8-7 大赢单正是止损终局后 3 分钟进场的）。

### M2 创新低近等容差（CHAN_CFG.nearEqualAtrK/nearEqualPct，默认关）

- madeNew 放宽：做多 `F.end − refer.end ∈ [0, tol]`（F 略高于参照低点）、做空对称，
  `tol = max(nearEqualAtrK×该级ATR, nearEqualPct×|refer价|)`（与 60m 近等双底同口径）；
- **护栏**：近等带内要求背驰三判据 AND（`_biDivergeStrictAll`，isBiDiverge 本体仍为 OR）；
  候选带 `nearEqual=True`；
- 实测仅 1 笔且为负贡献（见下），**保持默认关闭**。

## 不改动

isBiDiverge 本体、买卖点（findBuyPoints/findSellPoints）、trading_plan、buildBi 的
nearDouble 设置（15m 开取后底 = M3，曾实测 61 次触发/微观结构重排，已排除）、确认制链路。

## M4：检测周期「预期够笔」（固定口径）+ 背驰「分型确认进场」（页面可选，2026-09-11）

### 背景（8-6 21:00 案例，逐拍探针已核实）

X=60 信号 8-6 21:00（15m 背驰极值 4230.46）到 23:00 才成交 @4273.06（价差 +42.6、随后
stopSr -185）：不是幅度/间隔问题——10:00 顶 4304.31 → 21:00 低 4230.46 共 11 根时K、
74 点，幅度间隔早已够笔。卡的是**笔端点的底分型需右邻K收盘**：底分型落在 21:00 那根
小时K上，右邻（22:00~23:00 那根）23:00 收盘 → 60m 下跌笔 23:00 才出现在增量结构里
→ 闸①（末笔方向=down）此前一直把 X=60 整个跳过（背驰评估未运行）。分型识别固有
1 根本级K线滞后；确认底分型的右邻反弹与成交价变差同源。

### 规则

1. **检测周期预期够笔（BacktestEngine.expect_bi，回测页面可选，默认开；CHAN_CFG.expectBiEnough
   为非 WEB 调用方默认值。2026-09-11 二次调整：应用户要求从"固定"改回页面可选，False =
   M4 之前的原分型确认口径，便于页面上 A/B 两种口径）**：
   闸①与下沉链入口在「末笔方向与策略方向相反」时，不再等反向分型确认——末笔端点后
   已走出 ≥ expectBiMinBars（默认 5）根本级K线即视为「回调中/反弹中」：
   - 闸①：段起点改用末笔端点；信号带 `expectBi=True`；
   - 下沉链（`_sinkChainRealtimeNodes` expectMode）：以「末笔端点 → 下级末段当下极值」
     的**虚拟形成笔**为承载笔下沉（仅首个下沉层；下级末段未越过末笔端点 → 断链），
     其后层级恢复正常容器判定；
   - 安全性：末笔未被延伸（无同向新极值）说明反向段未被否定；反向段成笔质量由下沉
     链展开 ≥3 与背驰/支阻闸门保证。`counterMoveQualifies` 的计数**不含端点所在根**、
     含当根未收盘K线（与闸① _barsSince 口径一致）。
2. **背驰分型确认进场（BacktestEngine.diverge_confirm，回测页面可选，默认当下）**：
   候选成立后，若极值K线的右邻K未收盘（`tCut < 候选极值时间 + 2×该级bar间隔`）则本拍
   不出信号；右邻收盘后照常出信号 → 下一根 fine 开盘成交。口径为「右邻收盘 = 分型可见
   最早时刻」的**代理**（未做合并包含的严格分型校验）；段延伸（极值后移）时确认时钟
   自动重置。页面下拉：背驰进场 = 当下（默认）/ 分型确认后下一根开盘
   （webapp cfg `diverge_confirm`）。

### 不改动

确认制链路（JS mark_entry.js 无当下制路径，无需镜像）；isBiDiverge/买卖点/trading_plan/
buildBi；M1/M2 语义。

### 实施结果（2026-09-11，XAUUSD bars_all_tf.json 7-20 ~ 9-11 全量，webapp 默认参数）

| 口径 | 信号/成交 | 胜率 | PF | 已平仓盈亏 |
|---|---|---|---|---|
| M1+rearm（分型够笔，对照） | 67/52 | 37.3% | 2.01 | +799.2 |
| **M4 预期够笔（固定默认，minBars=5）** | 129/99 | 29.6% | 1.34 | +557.6 |
| M4 + 背驰分型确认（页面可选） | 117/94 | 30.1% | 1.29 | +440.8 |
| M4 预期够笔 minBars=8（扫描） | 124/95 | 29.8% | 1.31 | +503.3 |
| M4 预期够笔 minBars=11（扫描） | 104/78 | 32.5% | 1.52 | +671.8 |

- **目标案例达标**（语义正确性）：8-6 21:00 信号预期口径下 **21:15 @4238.56 成交**
  （对照分型口径 23:00 @4273.06），该笔 stopSr -47.0（对照 -185.04），且随后 23:45
  fallback 信号 00:21 @4226.89 +280.51 保留 → 窗口净 +233.5（对照 +95.5）。
- **全量代价（如实记录）**：预期口径新增 49 笔净 **-292.9**（大赢单 +261.2/+209.4/+143.3
  在列，但 X=15 预期口径高频小止损磨损占多）；胜率 37.3%→29.6%、PF 2.01→1.34。
  门槛扫描：minBars=11 可收窄至 -127（PF 1.52/+671.8）**且目标案例仍命中**（该案例
  端点后恰好 11 根）；默认保持 5（与形成段门槛同口径），是否上调由用户决定。
- **已知缺陷（divergeConfirm 臂发现，未修）**：被同向互斥压制的信号仍消耗段去重键，
  且 rearm 只按已成交 trade 的 (periodX, strategyKey, markRes) 重置——被压制信号所在段
  永久锁死。8-6 案例：分型确认臂中 21:00 mark=15 信号被 21:09 mark=3 抢先占坑压制后，
  23:45 的 fallback(+280.51) 因 markRes=15 键未重置而消失。修法方向：rearm 按
  (periodX, strategyKey) 全 markRes 重置，或压制信号不消耗 fired 键。

单测：test_divergence_fallback.py 13 用例（含 counterMoveQualifies 阈值、下沉链预期模式、
divergeConfirm 时序、expect_bi/diverge_confirm 引擎参数覆盖 CHAN_CFG；expect_bi=False
经引擎全链路核对精确还原旧口径——8-6 21:00 信号 23:00@4273.06 成交，True 则 21:15@4238.56）。
页面下拉：检测周期够笔 = 预期够笔（默认）/ 分型确认（expect_bi）；背驰进场 = 当下（默认）/
分型确认后下一根开盘（diverge_confirm）。
