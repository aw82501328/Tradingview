# 密集区自动调参

已实现于支阻调试页 `/sr` 的“自动调参”页签；`/sr?tab=auto` 可直接打开。

## 使用

1. 填写品种、起始日期，在左侧“周期独立参数”选择要校准的周期。
2. 新增样本，指定历史截止时刻或选择当前快照，点击“读取行情并预览”。首次读取会连接 TradingView；后续优先使用带品种校验的缓存。
3. 核对实际数据范围及截断前候选，输入多个人工价位和价格误差。支持换行、中英文逗号和分号；重复价位去重，每组最多 500 个价位。起始覆盖不足需明确确认实际范围后保存。
4. 累计多个历史样本，选择哪些参与拟合。样本编辑只改变标注、误差及启用状态；修改行情截止时间须创建新快照。
5. 开始优化。默认预算 300 秒，可选 60 秒，支持停止、继续；过程和最佳结果持久化。服务重启后任务为 interrupted，不自动重启。
6. 比较总体损失、样本匹配率、逐价位偏差和候选截断情况。点击“应用到当前周期”确认参数后，回填并调用现有重算；绘图继续使用原“画图”按钮。
7. 若需下次直接载入参数，在左侧保存预设；样本和搜索记录独立保存。

## 计算口径

- 每品种每周期独立拟合 `minTouch / clusterAtr / recentClusterAtr / recentBiCount`；不调整子类型开关、截断权重、合并或绘图参数。
- `sr_flip.cluster_candidates` 是正常计算和搜索共用的密集区生成入口。搜索只评价本周期截断前候选；不把人工价位硬插入算法结果。
- 每个快照先筛选 `from <= bar.time` 且 `bar.time + intervalSec <= cutoff`，再计算笔和 ATR。日周线沿用项目固定周期时长口径，未引入交易所日历或盘中历史重建。
- 同价候选（包括 flip/recent 重合）在匹配时算一个价位。使用矩形 Hungarian 最小代价分配，保证候选不能重复满足不同目标。排序仅用于确定性，不强制顺序匹配，因为容差边界使代价不满足单调匹配条件。
- 令 `d = abs(target - candidate) / tolerance`。匹配代价为 `0.1 × min(d, 3)`，容差外再加 `0.7`；未匹配代价为 `1`。容差边界采用微小浮点余量。
- 样本损失为其目标平均代价。周期损失为 `0.8 × 样本平均损失 + 0.2 × 最差样本损失`，加平均额外候选惩罚：`0.01 × (候选数 - 命中数) / (候选数 + 目标数)`。未标注价位不会像错误目标一样受罚。
- 初始范围为 minTouch 1–20、flip 容差 0.01–5 ATR、recent 容差 0.05–5 ATR、recent 笔数 1–200。可修改范围，当前参数始终作为比较基线，即使在范围之外。
- 固定种子联合探索与前八名组合的坐标细化交替进行，容差最终步长 0.01，整数参数最终步长 1。同分优先接近基线；无改善则保留基线，不承诺全局最优。
- 笔、ATR 和各子类型候选按快照缓存。搜索截止或停止时，未完成的组合不提交，续跑会重新评价该组合。
- 报告的截断标记依据每个历史快照与当前候选上限、评分权重计算。历史样本只有本周期行情，因此不伪造跨周期绘图结果；跨周期合并和最终选线在应用后的正常计算中查看。

## 数据、接口与兼容性

- 新配置 `clusterParamsByPeriod: {周期: {clusterAtr, recentClusterAtr, recentBiCount}}`。命中时覆盖共用默认，minTouch 沿用 `minTouchs`。旧预设没有新字段时保持原识别结果；载入旧预设会清空独立覆盖，避免沿用上一个预设的配置。
- 样本、任务记录和 gzip 行情快照保存在仓库 `.sr-tune/`（Git 忽略），原子替换写入。快照具有内容指纹；样本具有递增版本。样本删除采用软删除，不删除底层行情。
- 支阻调试页面改用同一份按品种、周期隔离的行情缓存。无品种信息的旧 `bars_all_tf.json` 不作为调参或支阻页面的可信缓存，也不会被这些新路径修改；其他旧调用路径保持兼容。
- `GET/POST /api/sr/tune/samples`；`DELETE /api/sr/tune/samples/{id}?version=N`。
- `POST /api/sr/tune/snapshots` 创建异步快照任务，GET 对应 job 取得实际覆盖、候选和建议误差。
- `GET/POST /api/sr/tune/jobs`；`GET /api/sr/tune/jobs/{id}`；`POST .../{id}/stop|resume|validate|apply`。
- 任务绑定样本版本、参数基线和范围。继续或应用时由服务端验证；apply 返回更新后的配置，由页面执行正常重算，不自动绘图。
- HTTP 后台任务与现有回测、实时、回放和标记操作共用活动状态及绘图锁。SSE 发布 `sr_tune` 进度事件，页面轮询恢复状态。
- 笔规则变更时需递增 `sr_tune.VERSION`，使旧搜索结果不能继续或应用；原始快照可重新构建。

## 周期参数入口整合（2026-09-09）

左侧「周期与参数」统一承载周期参与勾选、ATR 和当前周期的四项识别参数。点击周期名称切换编辑，样本存在未保存修改时阻止切换；加载与运行期间禁止切换。有效编辑即时写入页面配置。所有周期的 minTouch 均进入预设配置，包括未参与计算的周期。旧预设继续按共用默认值与周期覆盖值读取。右侧通用计算设置不再重复展示这四项输入，搜索范围作为折叠高级设置保留。数据面板保留缓存优先计算和刷新数据计算，移除右侧重复重算按钮。计算算法及旧版 Fibonacci 默认聚类行为不变。


## 预设 Excel 导入导出

预设行按保存、删除、导入、导出排列。导出读取该行已保存配置，生成 .xlsx 单表（预设参数），按路径、说明、类型、值记录所有字段，包含未知扩展字段和未勾选周期。导入校验文件格式、类型和计算参数后原子保存到该行预设并回填页面。额外的导入为新预设入口采用不冲突的名称。文件上限 2 MB，不接受公式；文件内文本按参数数据处理。可先导出作为模板并编辑参数值列。导入不会主动计算或画图。接口 POST /api/sr/presets/excel/export（JSON name），POST /api/sr/presets/excel/import?name=...（xlsx 二进制）。
