# 标记买卖点 mark-buy-sell 规格（SPEC）

> 文档用途：描述「标记买卖点」SKILL 的功能规格——基于各周期上画的笔，按缠论定义标记各周期的 1、2、3 类买卖点（红色文字，只在本周期显示）。
> 对应脚本：`.cursor/skills/mark-buy-sell/scripts/mark_buy_sell.js`（约 620 行）。
> 买卖点算法（findBuyPoints/findSellPoints 等）见 `chan-core/SPEC.md`。

## 1. 输入

| 项 | 来源 | 说明 |
|----|------|------|
| 笔数据 | `.cursor/cache/bis_<品种>.json`（chan-bi 画笔落盘） | **强制依赖**：与图上所画笔完全一致；缺文件或品种不符 → 报错退出 |
| K 线 | TradingView 图表实时读取 | 用于 ATR 偏移量、吸附到本周期 bar 边界（2026-10-14 规则v2 起 MACD 不参与买卖点判定） |
| 品种/当前周期 | 图表自动读取 | `chart.symbol()` / `chart.resolution()` |
| 参数 | 命令行 | 见下表 |

### 参数表

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--from=YYYY-MM-DD` | 无（必填） | 起始日期，所有周期都从该日期开始计算笔和买卖点 |
| `--periods=...` | `D,240,60,15,3` | 要标记的周期列表 |
| `--keep=N` | 10 | 每周期保留的标记总数（不分类：买+卖合并后只保留时间上最近的 N 个），减少图上标记数量 |
| `--atr=K` | 0.5 | ATR 过滤系数（透传，chan-bi 已用过） |
| `--gap=K` | 1.0 | 跳空独立成笔阈值（透传，写入 CHAN_CFG.gapFilter） |
| `--dry` | 关闭 | 只计算不打印（不绘图） |
| `--debug` | 关闭 | 打印锚定过程、标记列表等调试信息 |

## 2. 买卖点定义（2026-10-14 规则v2：背驰不参与判定，日线不标；旧逻辑备份=git 6971db6）

| 类型 | 定义（买侧表述，卖侧镜像） |
|------|------|
| **1买** | **已收笔上级上涨笔的起点 / 下跌笔的终点**，经 `projectFirstPoints` 落到笔内部的小级别顶点（落点阶梯见 chan-core SPEC §2.9）；同笔端点也照常标记（2026-10-16 起，共用端点先到先得只标一次）；尾段不补一类 |
| **2买** | 1买锚后低点**逐一抬高**（首个与锚价比、其后与前一低点比；未抬高只更新参照不标）——首个抬低 = 2买。强弱（用户口径）：反弹=**1买后到该候选为止的最高点** vs 前高=**1买之前最近的顶点**——过=强、没过=弱（当下即判） |
| **类2买** | 2买之后与其**同一个中枢内**（按时间归属同一段盘整）的后续抬低；不在同中枢的不标（交给三类）；主点不在中枢内则无类点 |
| **3买 / 类3买** | 价格**上破 zg 离开中枢后，回踩不再进该中枢**（`price > zg - thirdZsTol`）；序号窗口（每个已收笔上级上涨笔、**窗口内重新起算**）内**第 1 个被离开的中枢**：首个合格回踩=3买、其后=类3买；回踩重进则本轮结束（每枢计数不重置）；本枢序列收到下一个已离开中枢的离开笔起点（含该时刻回抽；未离开仍在三笔重叠完成处截断） |
| **4买 / 类4买** | 窗口内**第 2 个被离开的中枢**：首个=4买、其后=类4买；≥3 个中枢封顶类4买 |
| **2卖/类2卖** | 1卖锚后高点逐一压低：首个=2卖、同一中枢内后续=类2卖；强弱=反弹笔 vs 前低（过前低=强） |
| **3卖 / 类3卖 / 4卖 / 类4卖** | 下破 zd 离开中枢后**反抽不再进该中枢**（`price < zd + thirdZsTol`）；序号制与买侧同构 |

**方向开窗（管全部二三类点）**：上级已收笔上涨笔窗 (startTime, endTime] 只标买点、下跌笔窗只标卖点、未收笔尾段（最后已收笔终点之后）双向放行。**日线（无上级）不标买卖点。**

## 3. 处理流程

### 3.1 强制依赖画笔数据

- 读取 `bis_<品种>.json`（chan-bi 落盘），文件不存在 / 解析失败 / 品种不匹配 → **报错退出**；
- 本周期笔**直接从缓存读取**（`bisCache.periods[res]`），不再本地计算（mergeBars/findFractals/buildBi/ATR过滤/extendLastBi/校准 均由 chan-bi 完成并落盘）；
- 过滤到起始日期之后的笔（`endTime >= FROM_TS`，与画笔一致）。

### 3.2 计算买卖点（每周期，从大到小）

1. 计算 `atr = calcATR(rawBars, 14)`、`macdArr = calcMACD(rawBars)`（MACD 2026-10-14 规则v2 起不参与买卖点判定，仅为兼容保留计算与传参）；
2. `findBuyPoints(curBis, upperBis, macdArr, intervalSecOf(res), CLASS2_ZS_TOL, THIRD_ZS_TOL, upperMacdArr)`、`findSellPoints(...)`（规则v2：一类投影 + 二类抬低序列 + 三类逐中枢序号 + 方向开窗过滤，详见 chan-core SPEC §2.9）；日线周期（无上级）返回空、自动清除旧标记；
3. **保留全部新鲜买卖点**；
4. **一类点不二次锚定**（2026-10-13 起）：重复点位去重由 `projectFirstPoints` 按顶点时刻完成；
5. （2026-10-14 规则v3）**真1买/真1卖 邻近合并已删除**（mergeNearFirstSecond/--nearp/NEAR_ATR_RATIO 移除：价格就近不限时间差会跨月误合并，如 7-6 的 1卖 并入 10-13 的 2卖）；
6. **区间套动态更新（笔区间粒度，2026-10-14 规则v2）+ 保留截断**：脏周期（`changedBiSpan`+`nestedDirtyPeriods` 级联，span=并集）**脏区间 t0 之前的旧标记沿用上次结果、之后取本次新算**；没变的更大周期整体沿用；每周期不分类（买+卖合并）在**合并后的完整列表**上只保留时间上最近 N 个（`--keep=N` 默认 10）；
7. **汇总标记**：时间吸附到本周期 bar 边界（`snapToOwnBar`）；文字价格偏移 `max(atr×0.5, 0.05)`（买点在价格下方、卖点在价格上方）；
8. （2026-10-14 规则v3）**跨周期共振变绿已删除**：全部标记固定红色（color 字段保留恒红，eval 比对兼容）。

### 3.3 绘制

- 标记前先清除所有周期的旧买卖点标记（title = `CHAN_BUYSELL_<周期>`，每个周期在源周期下清除）；**删除后复核剩余、未删净自动重试最多 3 轮**（2026-10-14 加固：单轮枚举删除在形状过多/图表忙时会漏），仍删净不掉则打告警日志；
- **实例互斥锁**（2026-10-14 加固）：`.cursor/cache/buysell_mark.lock`——另一实例运行中则本次直接退出（webapp 自动任务与手动运行并发会在同一张图上交错清/画留残渣）；锁龄 >10 分钟或持锁进程已退出时可接管（崩溃自愈）；
- 绘制前 `ensureBarsCover` 确保图表数据覆盖最早标记时间（否则早期标记被吸附到数据边缘导致堆叠）；
- 创建 `text` 红色文字：`text=label`（如 `1买`）、`color` 恒红 `#F23645`、`bold: true`、`title=CHAN_BUYSELL_<周期>`；
- 可见范围 `onlyThisInterval(res)`：只在本周期显示（3分钟→仅3分钟、15分钟→仅15分钟、1小时→仅1小时、4小时→仅4小时、日线→仅日线）。

## 4. 输出

| 项 | 说明 |
|----|------|
| 图上标记 | `text` 红色文字（恒红），只在本周期显示，title = `CHAN_BUYSELL_<周期>` |
| 控制台日志 | 各周期买卖点结果（类型@时间(价格)）、锚定过程 |

## 5. 边界情况

| 场景 | 处理 |
|------|------|
| 笔数据文件不存在/解析失败/品种不符 | 报错退出，提示先运行「画笔」 |
| 某周期笔数据为空（画笔未覆盖） | 跳过该周期 |
| 某周期取数失败 | 等待 3s 重试一次，仍失败跳过 |
| 1买无上级笔底部端点可锚定 | 不标记该一买 |
| 多个一买候选锚到同一上级底 | 只保留一个标记 |
| 标记时间超出已加载数据范围 | ensureBarsCover 加载完整历史；**仍早于已加载首根K（容差1根K）的标记跳过不画**（2026-10-14 加固：此前会被吸附到首根K上堆积，10-14 实测 60m 堆 58 个/3m 堆 100 个），留在状态里待下次补画 |

| 中枢（chan-zs） | 独立绘制，本脚本不依赖 |
