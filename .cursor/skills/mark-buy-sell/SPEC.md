# 标记买卖点 mark-buy-sell 规格（SPEC）

> 文档用途：描述「标记买卖点」SKILL 的功能规格——基于各周期上画的笔，按缠论定义标记各周期的 1、2、3 类买卖点（红色文字，只在本周期显示）。
> 对应脚本：`.cursor/skills/mark-buy-sell/scripts/mark_buy_sell.js`（约 620 行）。
> 买卖点算法（findBuyPoints/findSellPoints 等）见 `chan-core/SPEC.md`。

## 1. 输入

| 项 | 来源 | 说明 |
|----|------|------|
| 笔数据 | `.cursor/cache/bis_<品种>.json`（chan-bi 画笔落盘） | **强制依赖**：与图上所画笔完全一致；缺文件或品种不符 → 报错退出 |
| K 线 | TradingView 图表实时读取 | 用于 ATR 偏移量、吸附到本周期 bar 边界、MACD 背驰判定 |
| 品种/当前周期 | 图表自动读取 | `chart.symbol()` / `chart.resolution()` |
| 参数 | 命令行 | 见下表 |

### 参数表

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--from=YYYY-MM-DD` | 无（必填） | 起始日期，所有周期都从该日期开始计算笔和买卖点 |
| `--periods=...` | `D,240,60,15,3` | 要标记的周期列表 |
| `--nearp=K` | 0.3 | 1类与2类价差阈值（ATR 倍数），价差 ≤ 该值视为很近并合并标注「真1买/真1卖」 |
| `--keep=N` | 1 | 每类买卖点保留的个数（只保留时间上最近的 N 个），减少图上标记数量 |
| `--atr=K` | 0.5 | ATR 过滤系数（透传，chan-bi 已用过） |
| `--gap=K` | 1.0 | 跳空独立成笔阈值（透传，写入 CHAN_CFG.gapFilter） |
| `--dry` | 关闭 | 只计算不打印（不绘图） |
| `--debug` | 关闭 | 打印锚定过程、标记列表等调试信息 |

## 2. 买卖点定义

| 类型 | 定义 |
|------|------|
| **1买** | 下跌笔创新低 + MACD 背驰（绿柱面积变小 或 黄白线低点抬高 或 绿柱最大高度变小）；与上级笔完全重合的笔跳过 |
| **1卖** | 上涨笔创新高 + MACD 背驰（红柱面积变小 或 黄白线高点变低 或 红柱最大高度变小）；与上级笔完全重合的笔跳过 |
| **2买/类2买** | 上一级别上涨笔段内的抬高低点（首个 `price > up.startPrice` 的下跌笔终点为 2买，其后更高的抬高低点为类2买）；无上级笔时用「结构底」 |
| **2卖/类2卖** | 上一级别下跌笔段内的次高点（首个 `price < dn.startPrice` 的上涨笔终点为 2卖，其后更低的次高点为类2卖）；无上级笔时用「结构顶」 |
| **3买** | 2买过后的上涨段未出现背驰（上涨笔创新高、突破前顶），其后的回调不破前顶且位于上级上涨笔段内 |
| **3卖** | 2卖过后的下跌段未出现背驰（下跌笔创新低、跌破前底），其后的反弹不破前底且位于上级下跌笔段内 |
| **真1买/真1卖** | 1类与2类价格很近时的合并标注（见下） |

## 3. 处理流程

### 3.1 强制依赖画笔数据

- 读取 `bis_<品种>.json`（chan-bi 落盘），文件不存在 / 解析失败 / 品种不匹配 → **报错退出**；
- 本周期笔**直接从缓存读取**（`bisCache.periods[res]`），不再本地计算（mergeBars/findFractals/buildBi/ATR过滤/extendLastBi/校准 均由 chan-bi 完成并落盘）；
- 过滤到起始日期之后的笔（`endTime >= FROM_TS`，与画笔一致）。

### 3.2 计算买卖点（每周期，从大到小）

1. 计算 `atr = calcATR(rawBars, 14)`、`macdArr = calcMACD(rawBars)`；
2. `findBuyPoints(curBis, upperBis, macdArr, intervalSecOf(res))`、`findSellPoints(...)`（区间套：2买/类2买只在上级上涨笔段内，2卖/类2卖只在上级下跌笔段内）；
3. **保留全部买卖点**，再做邻近合并（第 5 步）后，按 `--keep` 每类只保留时间上最近的 N 个（默认 1，见第 6 步）；
4. **一买锚定**（除日线/最外层外）：每个一买锚定到上一级某笔的底部端点（`anchorFirstBuy`），多个候选锚定到同一上级底只保留一个；找不到锚点则不标记该一买（2买/类2买基于结构底，不依赖一买锚定，保留）；
5. **邻近合并**（`mergeNearFirstSecond`）：1类与2类价格差 ≤ `max(atr × NEAR_ATR_RATIO, 0.05)` 时，把 1类 合并到最近的 2类 标记上标注为「真1买/真1卖」（原1类标记移除，2类保留；一个2类标记最多承接一个1类标记；附近无接近2类标记的1类保持原名）；
6. **每类保留最近 N 个**（`keepRecentEach`，`--keep=N` 默认 1）：1买/真1买/2买/类2买/3买/1卖/真1卖/2卖/类2卖/3卖 每类只保留时间上最近 N 个，避免图上标记过多；
7. **汇总标记**：时间吸附到本周期 bar 边界（`snapToOwnBar`）；文字价格偏移 `max(atr×0.5, 0.05)`（买点在价格下方、卖点在价格上方；真1买/真1卖与2类同点位，偏移双倍避免重叠）；
8. **跨周期共振**：本级别 1买/1卖 若与紧邻上一级别的 1/2/3 类买卖点落在同一点位（原始时间差 ≤ 60s、价格差 ≤ max(atr×0.2, 0.05)），本级别标记颜色改为绿色（表示同时是上级买卖点），其余保持红色。

### 3.3 绘制

- 标记前先清除所有周期的旧买卖点标记（title = `CHAN_BUYSELL_<周期>`，每个周期在源周期下清除）；
- 绘制前 `ensureBarsCover` 确保图表数据覆盖最早标记时间（否则早期标记被吸附到数据边缘导致堆叠）；
- 创建 `text` 红色文字：`text=label`（如 `1买`）、`color`（红 `#F23645` / 绿 `#089981`）、`bold: true`、`title=CHAN_BUYSELL_<周期>`；
- 可见范围 `onlyThisInterval(res)`：只在本周期显示（3分钟→仅3分钟、15分钟→仅15分钟、1小时→仅1小时、4小时→仅4小时、日线→仅日线）。

## 4. 输出

| 项 | 说明 |
|----|------|
| 图上标记 | `text` 红色/绿色文字，只在本周期显示，title = `CHAN_BUYSELL_<周期>` |
| 控制台日志 | 各周期买卖点结果（类型@时间(价格)）、锚定过程、邻近合并、共振标记 |

## 5. 边界情况

| 场景 | 处理 |
|------|------|
| 笔数据文件不存在/解析失败/品种不符 | 报错退出，提示先运行「画笔」 |
| 某周期笔数据为空（画笔未覆盖） | 跳过该周期 |
| 某周期取数失败 | 等待 3s 重试一次，仍失败跳过 |
| 1买无上级笔底部端点可锚定 | 不标记该一买 |
| 1类附近无价格接近的2类 | 1类保持原名（不合并） |
| 多个一买候选锚到同一上级底 | 只保留一个标记 |
| 标记时间超出已加载数据范围 | 绘制前 ensureBarsCover 加载完整历史 |

## 6. 与其他模块的依赖

| 模块 | 关系 |
|------|------|
| `chan-bi`（画笔） | **强制依赖**：读取其落盘笔数据 `bis_<品种>.json` |
| `chan-core` | 复用买卖点/背驰/ATR/MACD 等算法 |
| 中枢（chan-zs） | 独立绘制，本脚本不依赖 |
