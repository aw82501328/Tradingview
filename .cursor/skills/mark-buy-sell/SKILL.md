# 缠论买卖点标记

通过 CDP 连接 TradingView Desktop，基于**各周期上画的笔**，按照缠论定义在图上标记各周期的 **1、2、3 类买卖点**（红色文字，跨周期共振点用绿色文字）。

> **算法来源**：所有缠论算法（含买卖点识别）由 **`chan-core`**（`.cursor/skills/chan-core/scripts/chan_core.js`）提供（唯一算法源），本脚本只负责读取笔数据、调算法、绘制标记。修改算法规则请改 `chan-core`。
>
> **强制依赖画笔数据**：本 SKILL **不再自己计算笔**，而是**强制读取 `chan-bi` 画笔 SKILL 落盘的笔数据文件**（`.cursor/cache/bis_<品种>.json`）。如果文件不存在、或文件品种与当前图表品种不一致，脚本会**报错退出**，必须先对当前品种运行「画笔」后再标记买卖点。

## 前置条件

1. TradingView Desktop 以调试模式启动：`TradingView.exe --remote-debugging-port=9222`
2. 已打开至少一张图表，且图表停留在**要标记的品种**上（脚本自动读取当前品种和周期）
3. chrome-remote-interface 已安装（在 `server-cdp/node_modules/`）
4. **已对该品种运行过「画笔」**（chan-bi SKILL），生成了 `.cursor/cache/bis_<品种>.json` 笔数据文件

## 使用方式

```bash
# 在图表上标记各周期买卖点（必须指定起始日期，默认标记 日线/4小时/1小时/15分钟/3分钟 五个周期）
node .cursor/skills/mark-buy-sell/scripts/mark_buy_sell.js --from=2026-07-02

# 只计算并打印买卖点，不绘图（先验证再标）
node .cursor/skills/mark-buy-sell/scripts/mark_buy_sell.js --dry --from=2026-07-02

# 只标记指定周期（例如只标 1小时 和 4小时）
node .cursor/skills/mark-buy-sell/scripts/mark_buy_sell.js --from=2026-07-02 --periods=240,60
```

> `--from` 起始日期应与画笔时一致（脚本会读取该日期之后的笔数据来计算买卖点）。

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--from=YYYY-MM-DD` | **必填**：起始日期，所有周期都从该日期开始计算笔和买卖点 | 无（缺少时报错退出） |
| `--periods=...` | 要标记的周期列表（逗号分隔，从大到小） | `D,240,60,15,3` |
| `--dry` | 只计算不绘图 | 关闭 |
| `--debug` | 打印锚定过程、标记列表等调试信息 | 关闭 |

## 起始日期规则（每次标记必做，且必须输入日期）

**用户说「标记买卖点」时，必须先询问「起始日期」（格式 `YYYY-MM-DD`，如 `2026-07-02`），得到日期后再执行标记。不得在未获得日期的情况下直接运行脚本。**

```
① 询问：本次标记买卖点从哪个日期开始？（格式 YYYY-MM-DD，如 2026-07-02）
② 用户给出日期 → 运行 node mark_buy_sell.js --from=YYYY-MM-DD
③ 用户未给出明确日期 → 再次询问，直到获得日期后才执行
```

## 标记规则

### 标记前先清除旧标记

每次标记买卖点前，会先**清除已经存在的买卖点标记**：
- 脚本开始会依次切到各周期，删除所有标签为 `CHAN_BUYSELL_<周期>` 的图形
- 然后重新计算并在各周期绘制最新的买卖点

### 基于各周期的笔（强制读盘）

买卖点基于**各周期自己画的笔**计算：脚本读取 `chan-bi` 画笔 SKILL 落盘的
`.cursor/cache/bis_<品种>.json` 笔数据文件（该文件包含各周期已完成 ATR过滤、未完成笔延伸、
跨周期端点校准的最终笔，与图上所画笔完全一致），然后调用 `chan-core` 的买卖点算法计算并标记。

- 找不到笔数据文件 / 品种不匹配 → **报错退出**，提示先运行「画笔」；
- 某周期在笔数据文件中没有笔（画笔未覆盖该周期）→ 跳过该周期并提示；
- 仍会读取当前周期K线，仅用于：买卖点文字偏移量（ATR）、标记吸附到本周期bar边界、MACD 背驰判定。

### 买卖点定义（缠论）

| 类型 | 定义 |
|------|------|
| 一买 | 下跌笔创新低 + **MACD 背驰**（绿柱面积变小 或 黄白线低点抬高，下跌动能减弱）。**只有背驰才标记 1买** |
| 二买 | **上一级别上涨笔段内**的第一个抬高低点（高于段起点） |
| 类2买 | 二买之后第一个更高的低点（不破二买） |
| 三买 | **二买过后的上涨段未出现背驰**（上涨笔创新高、突破前顶），其后回调下跌笔**不破该前顶**（前顶 = 二买之前最近一个上涨笔的结束点）。与一买/背驰无关。**对每一笔二买**都在其后寻找（扫描范围限制到下一个二买之前，每个二买段最多标一个三买），取段内**最后**满足「突破前顶的上涨笔 + 其后第一个回调不破前顶」的组合；**区间套**：回调结束点须位于**上一级别上涨笔段内**，且**回调价须高于该上涨笔的起点价**（排除回调恰好落在上级笔起点/新段启动点，如 7-29、8-13 22:00 这类位置） |
| 一卖 | 上涨笔创新高 + **MACD 背驰**（红柱面积变小 或 黄白线高点变低，上涨动能减弱）。**只有背驰才标记 1卖** |
| 二卖 | **上一级别下跌笔段内**的第一个次高点（低于段起点） |
| 类2卖 | 二卖之后第一个更低次高点（不破二卖） |
| 三卖 | **二卖过后的下跌段未出现背驰**（下跌笔创新低、跌破前底），其后回调上涨笔**不破该前底**（前底 = 二卖之前最近一个下跌笔的结束点）。与一卖/背驰无关。**对每一笔二卖**都在其后寻找（扫描范围限制到下一个二卖之前，每个二卖段最多标一个三卖），取段内**最后**满足「跌破前底的下跌笔 + 其后第一个反弹不破前底」的组合；**区间套**：反弹结束点须位于**上一级别下跌笔段内**，且**反弹价须低于该下跌笔的起点价**（排除反弹恰好落在上级笔起点/新段启动点）。例：1小时 二卖 = 7-25 05:45(98.87)，前底 = 7-24 23:30(95.13，二卖之前最近下跌笔结束点)；其后下跌笔 7-25 05:45 → 7-27 17:45(84.65) 跌破前底，反弹笔 7-27 17:45 → 7-27 21:15(87.43) 不破前底、且位于 4小时 下跌笔(7-24 02:00→7-29 00:00) 内部 → **3卖 = 7-27 21:15(87.43)**。同一位置若同时满足类2卖，优先标记为 3卖 |

**MACD 背驰判定（1买/1卖 的必备条件）**：
- 比较**当前笔**与其前一个**参照笔**（向前找最近的有效同向笔，跳过幅度不足当前笔 50% 的次级别回调）的 MACD 动能指标；
- 背驰 = 满足以下**任一**（OR）：
  1. **MACD 柱状体面积变小**：
     - 底背驰（一买）：下跌笔区间内绿柱面积（macd<0 柱绝对值累加）小于参照下跌笔；
     - 顶背驰（一卖）：上涨笔区间内红柱面积（macd>0 柱累加）小于参照上涨笔；
  2. **黄白线高度动能减弱**：
     - 底背驰（一买）：区间内 DIF 最低点**抬高**（高于参照笔的 DIF 低点）；
     - 顶背驰（一卖）：区间内 DIF 最高点**变低**（低于参照笔的 DIF 高点）。
- 只有满足背驰的下跌/上涨笔才标记 1买/1卖；**加速段**（面积变大、黄白线更极端，动能增强）不是背驰，不标记——例如 4小时 8-5(78.11) 加速赶底（绿柱 10.15 vs 0.05、DIF 低点更低）不标 1买，7-24(102) 加速顶不标 1卖。

**区间套原则（重要）**：
- 买卖点标记**必须以第一步画笔的结果（日线笔）为总框架**，逐级区间套；
- **2买/类2买** 只在「上一级别上涨笔」的时间段内找抬高低点；处于上一级别下跌笔段内的低点（下跌线段中的反弹低点）不标记买点——例如 4小时 **7-29 的 80.67** 位于日线下跌笔内部，是下跌线段的一部分，不标记类2买；
- **2卖/类2卖** 只在「上一级别下跌笔」的时间段内找次高点；
- **4小时（主要操作级别）保留区间套下的全部结构段标记**：例如 **7-11 的 75.22**（日线第一段上涨笔内）与 **8-13 的 85.85**（日线第三段上涨笔内）都标记 2买；
- **全部周期（日线/4小时/1小时/15分钟/3分钟）全部保留**各周期区间套下识别出的全部买卖点——包括 **全部 1买/1卖**（每个 MACD 背驰底/顶都标记，如 1小时 7-11(75.22) 与 7-29(80.67) 两个 1买 都保留）；多个候选锚定到同一上级位置时只保留一个（去重）。

**买点示例（4小时）**：日线笔 上涨(70.14→102)→下跌(102→78.11)→上涨(78.11→94.83)；4小时 2买 在日线第一段上涨笔内的 7-11(75.22) 与第三段上涨笔内的 8-13(85.85)，而日线下跌笔内部（如 80.67）不标买点。

**三买示例（1小时）**：2买 = 8-14 21:00(86.53)；2买 过后上涨笔 #45 涨至 8-20 20:00(94.71)，突破 2买 之前的前顶（88.69，即 2买 之前最近上涨笔的结束点），无背驰；其后回调笔 8-20 20:00 → 8-21 17:00(92.74) 不破前顶、且位于 4小时 上涨笔(8-13 22:00→8-22 00:00) 内部 → **3买 = 8-21 17:00(92.74)**。类似地，2买 = 8-7 20:00(81.50) 过后上涨笔 #39 涨至 8-11 16:00(90.03)，突破前顶 84.44，其后回调笔 8-11 16:00 → 8-11 21:00(86.60) 不破前顶、位于 4小时 上涨笔(8-5 08:00→8-12 12:00) 内部 → **3买 = 8-11 21:00(86.60)**。同一位置若同时满足类2买，优先标记为 3买。

**卖点示例（4小时）**：日线下跌笔(102→78.11) 段内，2卖 = 8-1(91.36)，类2卖 = 8-4(86.33)；1卖 = 最近背驰顶 8-22(94.83)。

**1买** 按 **MACD 背驰** 判定并锚定上一级别笔起点；**1卖** 按 **MACD 背驰** 判定并锚定上一级别**上涨笔的结束点**（见下方两节）。

### 一买锚定规则（跨周期对齐）

**低级别的一买必须锚定到「上一级别某笔的起点」**（即该级别结构转折处）：

| 周期 | 一买锚定基准 |
|------|------|
| 日线 | 无（最高级别，用本周期结构自行判定） |
| 4小时 | 日线一笔的起点 |
| 1小时 | 4小时一笔的起点 |
| 15分钟 | 1小时一笔的起点 |
| 3分钟 | 15分钟一笔的起点 |

实现逻辑：
1. 先按本周期笔计算出**候选一买**（创新低 + **MACD 背驰**：绿柱面积变小 或 黄白线低点抬高）；
2. 在上一级别笔列表中，取「候选一买时间之前、时间上最近的一个**底部端点**」（上一级别上涨笔的起点 或 下跌笔的终点）；
3. 该底部端点即为本次一买的标记位置（价格用上一级别底部端点价格，时间映射到本周期K线bar边界）。

即：**4小时的一买必然落在某根日线笔的起点处，1小时的一买必然落在某根4小时笔的起点处，以此类推。** 若上级笔中没有候选一买之前的底部端点，则该周期只不标记一买；2买/类2买 基于结构底独立计算，不受锚定影响，仍会标记。

### 一卖锚定规则（跨周期对齐，与一买对称）

**低级别的一卖必须锚定到「上一级别上涨笔的结束点」**（即上涨线段的终点）：

| 周期 | 一卖锚定基准 |
|------|------|
| 日线 | 无（最高级别，用本周期结构自行判定） |
| 4小时 | 日线上涨笔的结束点 |
| 1小时 | 4小时上涨笔的结束点 |
| 15分钟 | 1小时上涨笔的结束点 |
| 3分钟 | 15分钟上涨笔的结束点 |

实现逻辑：
1. 先按本周期笔计算出**候选一卖**（创新高 + **MACD 背驰**：红柱面积变小 或 黄白线高点变低）；
2. 若候选一卖位于某**上一级别上涨笔内部**（该上涨笔尚未结束，其 `endTime` 晚于候选一卖时间），说明上涨线段仍在延续，该局部顶**不是真正的 1卖**，一卖**上移**到该上级上涨笔的结束点（例如：15分钟 8-17 10:00 的局部高点位于 1小时上涨笔 8-14 21:00→8-20 20:00 内部，上涨仍在延续，因此一卖应标在 1小时上涨笔结束点 8-20 20:15 附近）；
3. 若候选一卖不在任何上级上涨笔内部，则取「候选一卖时间之前、时间上最近的一个**顶部端点**」（上一级别上涨笔的结束点 或 下跌笔的起点）对齐；
4. 价格用上级顶/上级上涨笔结束点价格，时间映射到本周期K线bar边界。

即：**低级别的一卖必然落在某根上级上涨笔的结束点处。** 2卖/类2卖 基于结构顶独立计算，不受锚定影响。

### 与上级笔完全重合不标记 1 类买卖点

若本周期某笔与**上一级别某笔完全重合**（起点、终点的时间与价格均一致），说明本周期该笔内部**无更细结构**——整笔就是上一级别的一笔，本周期无法在本级别判断背驰，该笔的 **1买/1卖 一律不标记，由上一级别标记**。

实现逻辑：在计算候选一买/一卖前，用 `isSameAsUpperBi(cur, upperBis, barSec)` 检查当前候选笔与上一级别全部笔是否完全重合（**时间容差 = 本周期 1 个 bar**、价格容差 0.01），若重合则直接跳过该笔，不参与背驰计算与一买/一卖生成；2买/3买/类2买 等不受影响，仍正常标记。

> **为什么时间容差取「本周期 1 个 bar」而非固定小值**：低级别笔用更低一级校准（如 15分钟 用 3分钟 校准，端点落在 3分钟 bar 边界如 21:39），上级笔用本周期校准（如 1小时 用 15分钟 校准，端点落在 15分钟 bar 边界如 21:30）。同笔的两端点时间可能相差最多一个本周期 bar（如 15分钟 8-14 16:12→21:39 与 1小时 8-14 16:00→21:30 实为同一笔下跌）。若容差过小（60 秒）会把实际同笔误判为不同笔，导致本周期仍标记 1类买卖点。

例1：15分钟 8-11 21:15(86.60) → 8-12 12:00(90.07) 这笔上涨与 1小时 同区间笔完全重合（15分钟内部无结构），因此 15分钟 不再标记 8-12 12:00 的 1卖，该 1卖 由 1小时 周期标记（1小时 8-12 12:00 仍正常标记）。

例2：15分钟 8-14 16:12(88.69) → 8-14 21:39(86.53) 这笔下跌与 1小时 8-14 16:00→21:30 同笔（价格一致、时间差 12/9 分钟），15分钟 不再标记 8-14 21:30 附近的 1买，由 1小时 标记。

## 显示规则

- 买卖点用**红色文字**标记（文本标签，如 `1买` `2买` `3买` `1卖` `2卖` `3卖`）；
- **跨周期共振标记改绿色**：本级别的 `1买`/`1卖` 若与**紧邻上一级别**的 1/2/3 类买卖点（含类2买/类2卖）落在**同一点位**（原始时间/价格一致，时间差 ≤ 60 秒、价格差 ≤ max(ATR×0.2, 0.05)），说明该 1 类点同时是上级买卖点，则该标记颜色改为**绿色**，其余保持红色。例：4小时 `2买@7-11 05:00(75.22)` 同时是 1小时 `1买@7-11 05:00(75.22)`，故 1小时的 1买 用绿色显示；15分钟 `1买@8-21 17:00` 同时是 1小时 `3买@8-21 17:00`，故 15分钟的 1买 用绿色显示；
- **只在该周期显示**：每个周期的买卖点通过 `intervalsVisibilities` 设置为只显示本周期（例如 4小时的买卖点只在 4小时 图可见，切到 1小时 自动隐藏），不会跨周期显示；
- 买点文字画在极值价格**下方**，卖点文字画在极值价格**上方**（偏移量按 ATR 自适应）；
- 标记不锁定，可自行编辑/拖动。

## 常见问题排查

| 问题 | 可能原因 | 检查命令 |
|------|----------|----------|
| ECONNREFUSED | TradingView 未以调试模式启动 | `netstat -ano \| findstr 9222` |
| 未找到页面 | 图表标签未打开 | 打开一张图表即可 |
| 提示缺少 --from | 未输入起始日期 | 必须询问用户起始日期后执行 |
| **报错「未找到 XX 的笔数据文件」** | 未先运行「画笔」SKILL（chan-bi），或缓存被清空 | 先对当前品种运行画笔（会生成 `.cursor/cache/bis_<品种>.json`），再运行本脚本 |
| **报错「笔数据文件属于 XX，与当前品种不一致」** | 缓存文件是其他品种画笔时生成的 | 先对当前品种运行画笔，再运行本脚本 |
| 某周期跳过（笔数据为空） | 画笔未覆盖该周期（如 `--periods` 未包含） | 用画笔 SKILL 重新画该周期 |
| 某周期没有一买标记 | 该周期下跌段未出现 MACD 背驰（加速赶底，绿柱面积变大/DIF 低点更低，如 4小时 8-5 78.11），或候选一买前没有上级笔底部端点锚定失败，或该笔与上级笔完全重合（内部无结构，由上级标记） | `--debug` 查看一买候选背驰对比日志 |
| 一卖标在上涨途中（如 15分钟 8-17 10:00） | 该局部顶位于上级上涨笔内部、上涨仍在延续，一卖已上移到上级上涨笔结束点（8-20 20:15） | 切换上级周期核对上涨笔结束点 |
| 某周期一卖/一买未标（如 15分钟 8-12 12:00） | 该笔与上一级别某笔完全重合（起点终点时间价格均一致），本周期内部无结构，无法判断背驰，由上一级别标记（1小时 8-12 12:00 仍会标 1卖） | `--debug` 查看「一卖跳过-与上级笔重合」日志 |
| 三买未标出 | 三买对每一笔二买后寻找（每段最多一个），需存在「突破前顶的上涨笔 + 其后第一个回调不破前顶」的组合，且回调须位于上级上涨笔内并高于该笔起点价；若回调跌破前顶、二买之后无创新高上涨段、或回调恰落在上级笔起点（新段启动点）则不标 | `--debug` 查看二买及前后笔结构 |
| 清除后旧标记还在 | 旧标记周期未在当前运行列表里 | 默认标记 D,240,60,15,3 全部周期 |

## 注意事项

- 脚本自动读取**当前图表**的品种和周期，切换品种后需重新运行。
- **必须先对该品种运行「画笔」**（chan-bi SKILL）生成笔数据文件，本脚本才能标记；否则报错退出。
- 本 SKILL 只负责买卖点标记，**不画笔、不清除笔**（画笔用 `chan-bi` SKILL）。
- 标记前会清除所有周期的旧买卖点（`CHAN_BUYSELL_*`），旧笔（`CHAN_BI_*`）不受影响。
