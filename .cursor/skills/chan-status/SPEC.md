# 当前状态 + 预判 chan-status 规格（SPEC）

> 文档用途：描述「chan-status」SKILL 的功能规格——描述各周期（日线/4小时/1小时/15分钟/3分钟）当前的结构状态，并对当下正在进行的K线做买卖点预判（1/2/3 类买卖点只要符合特征都预判）。
> 对应脚本：`.cursor/skills/chan-status/scripts/chan_status.js`。
> 算法来源：缠论算法复用 `chan-core`（唯一算法源）；状态分类与预判规则为本脚本 `predictPeriod` 纯函数（可单测）。

## 1. 输入

| 项 | 来源 | 说明 |
|----|------|------|
| 笔数据 | `chan-bi` 画笔落盘 `.cursor/cache/bis_<品种>.json`（**强制依赖**） | 各周期已 ATR 过滤、未完成笔延伸、跨周期端点校准的最终笔，与图上所画笔一致 |
| 支阻位数据 | `mark-sr-flip` 落盘 `.cursor/cache/srflip_<品种>.json`（**可选依赖**） | 用于原因中引用最近支阻，缺失时忽略 |
| 最新K线 | TradingView 图表实时读取（逐周期切换） | 计算 ATR / MACD / 最新收盘价（判断「回调/反弹进行中」） |
| 品种/当前周期 | 图表自动读取 | `chart.symbol()` / `chart.resolution()` |
| 参数 | 命令行 | 见下表 |

### 参数表

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--periods=...` | `D,240,60,15,3` | 要描述状态的周期列表（从大到小） |
| `--dry` | 关闭 | 只输出文本报告，不绘图 |
| `--debug` | 关闭 | 打印调试信息 |

## 2. 处理流程

### 2.1 数据读取与覆盖

- 逐周期 `ensureResolution(res)` 切换周期并等待K线加载稳定；
- `fetchBars(expectedIntervalSec)` 读取K线（用最后 20 个相邻间隔中位数判断真实周期，与期望不符重试）；
- 强制读取笔数据缓存：文件不存在 / 品种不匹配 → 报错退出（必须先运行「画笔」）；
- 可选读取支阻位缓存（不存在忽略）。

**数据来源时效性**：
- **价格实时**：`lastPrice`/`lastBarTime`/`macdArr`/`atr` 均来自 `fetchBars` 实时读取的页面K线（含最新未成笔K线）。
- **笔结构为快照**：`bis`/`upperBis` 来自 chan-bi 最近一次运行的缓存文件，本脚本不会用实时K线重算、延伸或补画新笔。凡依赖「是否已成笔/完成笔数」的判断（等待2买/2卖、上级极值后 ≤2笔、1类背驰参照区间）在画笔之后行情继续发展时可能滞后一拍；仅比较价格与笔终点的判断（回调/反弹中、2类运行中）不受影响。
- **约束**：本 SKILL 依赖「画笔先行」；在关键行情节点判断前建议先运行 chan-bi 刷新缓存，使笔结构与实时K线尽可能一致。

### 2.2 每周期状态计算（predictPeriod）

输入：`{ res, upperRes, bis, upperBis, macdArr, atr, lastPrice, lastBarTime, bars }`（`bis` 取最近 60 笔，`bars` 为本周期实时K线，用于震荡判定）。
输出：`{ res, upperRes, status, reason, pred, preds, label }`。

判断顺序（**震荡优先 + 所有预判基于区间套**，详见 SKILL.md 状态分类表）：
0. **【震荡优先】** `isRangeBound(bis, bars, atr, cfg)`：最近 `rangeBarN=40` 根K线 `maxHigh-minLow ≤ 5×ATR`；**笔端点区间（≤ 7×ATR）与涨跌交替只取「最近 40 根K线时间范围内」的笔判断（若 40 根K线内没有笔则跳过这两条）**→ 状态「震荡整理」，不输出买卖点预判。阈值均可覆盖；`bars` 缺失时跳过；
1. **【区间套优先】2卖/2买**：上级最近结构顶（底）已确认（`findUpperPeak/findUpperTrough`，取上级最后一笔起向前最近的上涨/下跌笔终点），本周期在其后**只完成≤2笔**（下跌/上涨第一笔 + 首次反弹/回调），当前反弹（回调）**不创新高（新低）**且价格在上方顶（下方底）之下（之上）→ 预判 2卖（2买）形成中 / **2卖（2买）运行中**（价格已反向穿越反弹高点/回调低点）；
2. **【区间套优先】上级上涨/下跌段内部运行中**：上级底（顶）已确认、本周期在其后只完成≤2笔且价格升破（跌破）上级底（顶），本周期上涨（下跌）笔运行中 → 状态「上级上涨段内部，上涨运行中，等待回调做2买」/「上级下跌段内部，下跌运行中，等待反弹做2卖」；
3. **预判3卖/3买**：最近 2卖（2买）之后出现创新低（新高）突破前底（前顶）的笔，当前反弹（回调）不破前底（前顶）→ 预判 3卖（3买）。仅当上级在其后已走出多笔（>2笔）时生效；
4. **预判1卖/1买**：最后一笔创新高（新低）+ `isBiDiverge` MACD 顶（底）背驰 → 预判 1卖（1买）；
5. **等待2买/2卖**：最后一笔上涨（下跌）后当前价已跌破（升过）该笔终点（回调/反弹进行中、未成新笔），且上级顶（底）未出现（或无上级=最高级别结构）→ 状态「回调/反弹进行中，等待2买/2卖」；
6. **区间套（上级下跌/上涨段内部）**：上级顶（底）**已确认**且当前价**已跌破（升破）上级顶（底）** → 本周期处于上级下跌（上涨）段内部：
   - 本周期最后上涨（下跌）笔终点**即上级顶（底）**（下跌/上涨第一笔中）→ 状态「上级下跌段内下跌第一笔进行中，等待反弹做2卖」/「上级上涨段内上涨第一笔进行中，等待回调做2买」；
   - 本周期已走出独立下跌（上涨）笔 → 状态「上级下跌段内部，等待反弹做2卖」/「上级上涨段内部，等待回调做2买」；
7. **延续**：创新高（新低）但未背驰 → 「上涨/下跌延续中」。

辅助函数：
- `findRefer`：向前找最近有效同向笔（幅度 ≥ 当前笔 50%），用于创新高（低）与背驰参照；
- `findUpperPeak/findUpperTrough`：上级最近结构顶/底（区间套优先判断的关键）；
- `isRangeBound`：震荡判定（K线区间 + 笔端点区间 + 涨跌交替，阈值可配置）；
- `checkThirdSell/checkThirdBuy`：3类预判判定；
- `labelBottom/labelTop`：1买/前低、1卖/前顶 标签（可判背驰时按背驰定，否则按结构底/顶）；
- 历史 2买/2卖 来自 `findBuyPoints/findSellPoints`（chan-core）。

### 2.3 表格汇总输出

逐周期计算后统一输出一张汇总表（列：周期 | 状态 | 原因 | 预判），每周期一行：

- `status`：状态一句话；
- `reason`：引用真实数据点说明原因；
- `pred`：主预判（类型+点位+条件）与附加预判（`preds`）合并为一个单元格，用 `；` 连接；
- 表格边框用 `printPeriodTable(rows)` 输出（中文按全角宽度对齐，列宽自适应）。

### 2.4 图上蓝色状态标记

- **清除**：切到各周期，按 title `CHAN_STATUS_<周期>` 清除该周期旧状态标记；
- **位置**：`最近 40 根K线最高点 + max(1.5×ATR, 0.5)`（顶部空白），时间 = `最新bar时间 + 2×本周期间隔`（最新bar右侧 2 根）；
- **样式**：`text` 蓝色 `#2962FF`、粗体、title `CHAN_STATUS_<周期>`、`intervalsVisibilities` 仅本周期显示、`lock:false`。

## 3. 输出

| 项 | 说明 |
|----|------|
| 文本报告 | 各周期「状态 + 原因 + 预判」输出到控制台 |
| 图上蓝色状态标记 | `CHAN_STATUS_<周期>` 蓝色文字，仅本周期可见，位于该周期图顶部空白处 |

## 4. 边界情况

| 场景 | 处理 |
|------|------|
| 未找到 TradingView 页面 | 报错退出 |
| 笔数据文件缺失 / 品种不匹配 | 报错退出，提示先运行「画笔」 |
| 某周期无K线或切换失败 | 跳过该周期 |
| 某周期笔数据为空（画笔未覆盖） | 跳过该周期并提示 |
| 笔数量不足 2 笔 | 状态 = 「数据不足」 |
| `findBuyPoints/findSellPoints` 抛错（数据不足） | try/catch 忽略，仅影响 3类/原因描述 |
| 支阻位缓存缺失 | 忽略（可选依赖） |

## 5. 与其他模块的依赖

| 模块 | 关系 |
|------|------|
| `chan-core` | 复用 `calcATR/calcMACD/isBiDiverge/findBuyPoints/findSellPoints/fmtT/intervalSecOf` |
| `chan-bi`（画笔） | **强制读取**本脚本落盘笔数据 |
| `mark-sr-flip`（支阻位） | **可选读取**落盘支阻位数据 |
| `mark-buy-sell`（买卖点） | 独立（本 SKILL 只预判，不重复标记历史买卖点） |
