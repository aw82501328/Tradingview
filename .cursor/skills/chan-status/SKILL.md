# 当前状态描述 + 当下预判

通过 CDP 连接 TradingView Desktop，读取 **`chan-bi`（画笔）SKILL 落盘的笔数据**，描述各周期（日线/4小时/1小时/15分钟/3分钟）当前处于什么结构位置，并对**当下正在进行的K线**做买卖点预判（1/2/3 类买卖点只要符合特征都预判）。
输出**文本报告（状态 + 原因 + 预判）**，并在图上用**蓝色文字**在对应周期的**空白处**标记该周期的状态。

> **算法来源**：所有缠论算法（含买卖点识别）由 **`chan-core`**（`.cursor/skills/chan-core/scripts/chan_core.js`）提供（唯一算法源）；本脚本只负责读取笔数据、调算法、做状态分类与预判、输出报告与绘制。状态分类与预判规则（非标准缠论算法，类似支阻位）为自定义逻辑，实现在本脚本 `predictPeriod` 纯函数内（可单测）。
>
> **强制依赖画笔数据**：本 SKILL **不计算笔**，**强制读取 `chan-bi` 画笔 SKILL 落盘的笔数据文件**（`.cursor/cache/bis_<品种>.json`）。如果文件不存在、或文件品种与当前图表品种不一致，脚本会**报错退出**，必须先对当前品种运行「画笔」（chan-bi）后再查看状态。
>
> **可选依赖支阻位**：若存在 `srflip_<品种>.json`，可在原因中引用最近支阻；缺失时忽略，不影响输出。

## 前置条件

1. TradingView Desktop 以调试模式启动：`TradingView.exe --remote-debugging-port=9222`
2. 已打开至少一张图表，且图表停留在**要查看的品种**上（脚本自动读取当前品种和周期）
3. chrome-remote-interface 已安装（在 `server-cdp/node_modules/`）
4. **已对该品种运行过「画笔」**（chan-bi SKILL），生成了 `.cursor/cache/bis_<品种>.json` 笔数据文件

## 使用方式

```bash
# 输出全部周期状态报告，并在图上画蓝色状态标记
node .cursor/skills/chan-status/scripts/chan_status.js

# 只输出文本报告，不绘图
node .cursor/skills/chan-status/scripts/chan_status.js --dry

# 只描述指定周期（例如 4小时 和 1小时）
node .cursor/skills/chan-status/scripts/chan_status.js --periods=240,60
```

> 不需要 `--from`：状态只看最新结构，直接读取画笔落盘的最新笔数据。

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--periods=...` | 周期列表（逗号分隔，从大到小） | `D,240,60,15,3` |
| `--dry` | 只输出文本报告，不绘图 | 关闭 |
| `--debug` | 打印调试信息 | 关闭 |

## 输出格式

控制台输出一张**汇总表**（列：周期 | 状态 | 原因 | 预判），每周期一行：

```
┌──────┬──────────────────────────────────┬───────────────────────────────┬───────────────────────────────┐
│ 周期 │ 状态                             │ 原因                          │ 预判                          │
├──────┼──────────────────────────────────┼───────────────────────────────┼───────────────────────────────┤
│ D    │ 上涨见顶回调进行中，等待2买      │ 1买(7-17 21:00 3959.8)后上涨  │ 预判2买 @8-28 05:00(4454.99)； │
│      │                                  │ 737.3 点，强过前期结构高点...  │ 回调不破 3959.80 则2买成立      │
│ 240  │ 2卖运行中                       │ 上级(D)顶 8-25 05:00 4697.105 │ （无）                          │
│ 60   │ 上级下跌段内下跌第一笔进行中，  │ 上级(240)顶 8-28 22:00 4631.98 │ （无）                          │
│      │ 等待反弹做2卖                   │ 已确认，当前价已跌破，正处于  │                                  │
│      │                                  │ 上级下跌段的第一笔下跌中        │                                  │
│ 15   │ 2卖运行中                       │ 上级(60)顶 8-28 22:00 4631.98 │ （无）                          │
│      │                                  │ 后先跌至 4445.455 再反弹不创   │                                  │
│      │                                  │ 新高，当前价已跌破反弹高点      │                                  │
│ ...  │ ...                              │ ...                            │ ...                            │
└──────┴──────────────────────────────────┴───────────────────────────────┴───────────────────────────────┘
```

- **周期**：周期名（D/240/60/15/3）；
- **状态**：一句话描述当前结构位置（见下节状态分类）；
- **原因**：引用真实数据点（买卖点位置、幅度、创新高/新低、MACD 背驰、是否已成笔）说明为什么是这个状态；
- **预判**：可预判的买卖点类型 + 点位 + 成立条件（主预判与附加预判用 `；` 合并），无预判时为空。

## 状态分类与预判规则

对每个周期取**最后一笔** `last`（可能延伸中）和最新价。**所有预判基于区间套**：先判断上级级别所处结构（上级最近结构顶/底 + 本级别在其后的完成笔数），再落到具体买卖点。判断顺序：

| 当前结构 | 状态 | 预判 |
|---------|------|------|
| **【震荡优先】** 最近 `rangeBarN=40` 根K线 `maxHigh-minLow ≤ 5×ATR`，且「最近 40 根K线**时间范围内**」的 `rangeBiN=4` 笔端点极差 ≤ 7×ATR（**若 40 根K线内没有笔则跳过该条件与涨跌交替**），且涨跌交替（同时有 up/down、无连续3笔同向） | **震荡整理**（K线重叠度高、价格变化不大、无明确方向，覆盖一切买卖点预判） | 无（等待方向选择） |
| **【区间套优先】** 上级最近结构顶已确认，本周期在其后**只完成≤2笔**（下跌第一笔+首次反弹），当前反弹**不创新高**且价格在上方结构顶之下 | **2卖运行中**（当前价已回落跌破反弹高点）/ 上级下跌段内反弹不创新高，预判2卖形成中（仍在反弹高位） | 2卖 @反弹高点 |
| **【区间套优先】** 上级最近结构底已确认，本周期在其后**只完成≤2笔**（上涨第一笔+首次回调），当前回调**不创新低**且价格在下方结构底之上 | **2买运行中**（当前价已反弹升破回调低点）/ 上级上涨段内回调不创新低，预判2买形成中（仍在回调低位） | 2买 @回调低点 |
| **【区间套优先】** 上级底已确认、本周期在其后**只完成≤2笔**且价格升破上级底，本周期上涨笔运行中 | 上级上涨段内部，上涨运行中，等待回调做2买 | 2买 @回调低点 |
| **【区间套优先】** 上级顶已确认、本周期在其后**只完成≤2笔**且价格跌破上级顶，本周期下跌笔运行中 | 上级下跌段内部，下跌运行中，等待反弹做2卖 | 2卖 @反弹高点 |
| 上级顶已确认且价格跌破上级顶，本周期最后上涨笔终点**即上级顶**（下跌第一笔中） | 上级下跌段内下跌第一笔进行中，等待反弹做2卖 | 2卖 @反弹高点 |
| 上级底已确认且价格升破上级底，本周期最后下跌笔终点**即上级底**（上涨第一笔中） | 上级上涨段内上涨第一笔进行中，等待回调做2买 | 2买 @回调低点 |
| 上级顶已现后本周期**已走出独立下跌笔**（下跌段内部） | 上级下跌段内部，等待反弹做2卖 | 2卖 @反弹高点 |
| 上级底已现后本周期**已走出独立上涨笔**（上涨段内部） | 上级上涨段内部，等待回调做2买 | 2买 @回调低点 |
| 最近 2卖 之后出现**创新低跌破前底**的下跌笔，当前反弹**不破前底**（且上级在其后已走出多笔） | 预判3卖形成中 | 3卖 @反弹高点 |
| 最近 2买 之后出现**创新高突破前顶**的上涨笔，当前回调**不破前顶**（且上级在其后已走出多笔） | 预判3买形成中 | 3买 @回调低点 |
| 上涨笔**创新高** + **MACD 顶背驰**（红柱面积变小 或 DIF高点变低 或 红柱最大高度变小） | 上涨创新高出现顶背驰，预判1卖 | 1卖 @高点（若回落确认） |
| 下跌笔**创新低** + **MACD 底背驰**（绿柱面积变小 或 DIF低点抬高 或 绿柱最大高度变小） | 下跌创新低出现底背驰，预判1买 | 1买 @低点（若止跌确认） |
| 上涨笔后当前价**已跌破该笔终点**（回调中，未成新下跌笔），且**上级顶未出现**（或无上级=最高级别） | 上涨见顶回调进行中，等待2买 | 2买 @回调低点（不破该笔起点则成立） |
| 下跌笔后当前价**已升过该笔终点**（反弹中，未成新上涨笔），且**上级底未出现** | 下跌见底反弹进行中，等待2卖 | 2卖 @反弹高点（不破该笔起点则成立） |
| 上涨笔创新高但 **MACD 未背驰** | 上涨延续中（创新高未背驰） | 无（关注后续背驰/回调） |
| 下跌笔创新低但 **MACD 未背驰** | 下跌延续中（创新低未背驰） | 无 |

> **区间套说明**：上级最近结构顶/底取上级最后一笔起向前最近的上涨/下跌笔终点（无论上级最后一笔类型）。「完成≤2笔」指本周期在上级极值时间之后已完成的笔数。区间套优先含义：上级级别刚进入下跌（上涨）段、内部只完成1-2笔时，本周期一律以 **2卖（2买）** 解读（下跌第一笔后的首次反弹/回调），而不是按本周期自身历史买卖点判 3类/1类；只有上级在其后已走出多笔（下跌/上涨结构充分展开）时才判 3类/1类。

> **震荡优先说明**：震荡判定基于实时K线（`bars`）与笔端点，阈值可用参数覆盖（`rangeBarN` 默认 40、`rangeBiN` 默认 4、`rangeKMult` 默认 5.0、`rangeBiMult` 默认 7.0，均可按 ATR 倍数理解）。K线区间须低于阈值；**笔端点区间/涨跌交替只取「最近 40 根K线时间范围内」的笔来判断（若 40 根K线内没有笔，则跳过这两条，仅按K线区间判定）**——避免用 40 根K线范围之外的远古笔否定当前震荡。判定为震荡时不再输出买卖点预判。

**为什么只对「正在进行的结构」预判**：1类买卖点需要 MACD 背驰 + 结构确认，3类需要「突破后回调不破」，均可在结构未走完时预判其形成；预判点位用当前笔的极值（反弹高点/回调低点），并注明成立条件。

## 显示规则（图上蓝色标记）

- 用**蓝色文字**（`#2962FF`、粗体）在对应周期图的**空白处**标记该周期状态（如 `等待2买`、`预判2卖`、`预判3卖`）；
- **位置**：该周期**最近 40 根K线最高点上方 + 1.5×ATR**（顶部空白），时间 = 最新bar右侧 2 根bar（不遮挡K线主体）；
- **只在该周期显示**：通过 `intervalsVisibilities` 设置为**只显示本周期**（切到其他周期自动隐藏）；
- 标记 title = `CHAN_STATUS_<周期>`，再次运行会先清除旧的该周期状态标记，不影响笔/买卖点/支阻位等其它标记；
- 标记不锁定，可自行编辑/拖动。

## 常见问题排查

| 问题 | 可能原因 | 检查命令 |
|------|----------|----------|
| ECONNREFUSED | TradingView 未以调试模式启动 | `netstat -ano \| findstr 9222` |
| 未找到页面 | 图表标签未打开 | 打开一张图表即可 |
| **报错「未找到 XX 的笔数据文件」** | 未先运行「画笔」SKILL（chan-bi），或缓存被清空 | 先对当前品种运行画笔（生成 `.cursor/cache/bis_<品种>.json`），再运行本脚本 |
| 某周期状态为「数据不足」 | 该周期笔数不足 2 笔 | 用画笔 SKILL 重新画该周期 |
| 某周期无预判 | 当前结构不满足任何预判条件（如上涨延续未背驰、上级下跌段内反弹等） | 参考状态分类表 |

## 注意事项

- 脚本自动读取**当前图表**的品种和周期，切换品种后需重新运行。
- **必须先对该品种运行「画笔」**（chan-bi SKILL）生成笔数据文件，本脚本才能输出状态；否则报错退出。
- 本 SKILL **不画笔、不标记历史买卖点**（画笔用 `chan-bi`，历史买卖点用 `mark-buy-sell`），只描述当前状态 + 预判当下。

### 数据时效性

- **价格实时、笔结构为快照**：`lastPrice` 等价格数据运行时通过 CDP 从页面实时读取（含最新未成笔K线）；但**笔结构**（最后一笔、上级顶/底、上级极值后本级别完成笔数等）来自最近一次「画笔」（chan-bi）的缓存文件，是画笔运行时刻的定格，本脚本**不会**用实时K线重新延伸或补画新笔。
- **受影响的状态**：依赖「是否已走出新笔」的判断——「等待2买/2卖」（回调未成笔）、「上级段内 ≤2笔」（区间套优先）、「预判1卖/1买」（背驰参照区间）。画笔之后行情继续发展，这些状态可能滞后一拍。
- **基本不受影响的状态**：只比较「当前价 与 笔终点/上级极值」——「回调/反弹进行中」「2卖/2买运行中」「上级段内部运行中」等。
- **建议**：在关键行情节点做状态判断前，先运行「画笔」刷新缓存，再运行本脚本；画笔与判断之间的行情变化越小，判断越准。
