# 画笔 chan-bi 规格（SPEC）

> 文档用途：描述「画笔」SKILL 的功能规格——在 TradingView Desktop 图表上按缠论理论画笔，并以嵌套（区间套）方式从大到小绘制各周期笔。中枢（缠论中枢矩形）由独立 chan-zs SKILL 绘制（读取本脚本落盘的笔数据）。
> 对应脚本：`.cursor/skills/chan-bi/scripts/chan_bi.js`（约 705 行）。
> 算法实现见 `chan-core/SPEC.md`（本脚本复用 chan-core 全部笔算法）。

## 1. 输入

| 项 | 来源 | 说明 |
|----|------|------|
| K 线 | TradingView 图表实时读取 | 各周期分别读取；`--from` 时从指定日期开始 |
| 品种/当前周期 | 图表自动读取 | `chart.symbol()` / `chart.resolution()` |
| 参数 | 命令行 | 见下表 |

### 参数表

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--bars=N` | 200 | 取最近 N 根K线（仅在未指定日线起点时用于最外层/日线） |
| `--atr=K` | 0.5 | ATR 过滤系数：幅度 `< atr×ATR` 的笔剔除 |
| `--gap=K` | 1.0 | 跳空独立成笔阈值（缺口 ≥ gap×ATR 强制独立成笔），会写入 `CHAN_CFG.gapFilter` |
| `--periods=...` | `D,240,60,15,3` | 要绘制的周期列表（从大到小） |
| `--from=YYYY-MM-DD` | 无 | 指定日线起点日期，从该日期的日K开始画，嵌套到各级别 |
| `--dry` | 关闭 | 只计算不绘图 |
| `--debug` | 关闭 | 打印调试信息（含 buildBi 过程） |

## 2. 绘制配置

### 颜色（按周期，复用为支阻位/进出场等颜色基准）

| 周期 | 颜色 |
|------|------|
| 3分钟 | 青蓝 `#00BCD4` |
| 15分钟 | 紫 `#8A2BE2` |
| 1小时 | 黄 `#FFD700` |
| 4小时 | 蓝 `#2962FF` |
| 日线 | 红 `#F23645` |
| 周线 | 绿 `#089981` |
| 其他 | 紫 `#8A2BE2` |

### 可见范围（intervalsVisibilities）

某周期的笔只显示在「该周期 + 低一级周期」，其余周期隐藏：

| 周期 | 显示在 |
|------|--------|
| 3分钟 | 30秒、3分钟 |
| 15分钟 | 3分钟、15分钟 |
| 1小时 | 15分钟、1小时 |
| 4小时 | 1小时、4小时 |
| 日线 | 4小时、日线 |
| 周线 | 日线、周线 |

通过设置 shape 的 `intervalsVisibilities`（大类开关 + from/to 范围）实现；未列出的周期不限制（返回 null）。shape 不锁定（`lock:false`），用户可在图上右键修改可见周期。

## 3. 处理流程

### 3.1 K 线读取与数据覆盖

- `ensureResolution(res)`：切换周期并等待K线加载完成（长度连续两次一致视为稳定）；
- `fetchBars(expectedIntervalSec, fromTs, buffer, windowDays)`：
  - 用最后 20 个相邻间隔的中位数判断真实周期（避免停牌缺口误判），与期望周期不符则重试等待；
  - 数据起点晚于起始日期较多（未覆盖）→ `scrollToFirstBar` 加载完整历史后重试，加载完滚回实时；
  - 容忍度 = `max(24×K线间隔, 6小时)`；
  - **小周期窗口（windowDays）**：3分钟/15分钟 周期传入窗口天数后，覆盖目标从 `fromTs` 改为
    `max(fromTs, 最新K线时间 - windowDays×86400)`——只需加载最近 N 天数据即通过覆盖检查，
    避免 3分钟 为覆盖起始日期加载数月完整历史而超时（曾导致 3分钟 周期被跳过）；
  - 始终没等到目标周期数据 → 返回 null，跳过该周期（避免用错误周期K线画图）。

### 3.2 嵌套窗口确定（多周期从大到小）

- 第 1 层（日线）：`--from` 时从该日期开始；否则取最近 `N_BARS`（200）根K线；
- 第 2 层起：以上一层**最后一笔的起点**为锚（`anchorStart`），取该锚点之后的K线，锚点前补 `ANCHOR_BUFFER`（30）根缓冲；锚点范围内K线不足 `MIN_WINDOW_BARS`（20）根时从外层笔列表从后往前扩展锚点；
- 绘制时只画「结束时间 ≥ 锚点」的笔（锚点前缓冲仅保证分型完整）。

### 3.3 笔计算（每周期）

1. `mergeBars`（包含合并）→ `findFractals`（分型）；
2. `calcATR(rawBars, 14)`（供跳空判定）→ `calcMACD(rawBars)`（供 MACD 变色成笔）；
3. `lockedPivotsOf(prevBis)` 取上级笔端点作为锁定端点 → `buildBi(fractals, merged, atr, macdArr, lockedPivots)`（区间套强制对齐）；
4. `fixBiExtremes(bis, merged)`（端点极值修正）；
5. **ATR 过滤**：`span < atr×ATR_FILTER` 的笔剔除（`ATR_FILTER` 默认 0.5）；
6. `extendLastBi`（未完成笔延伸）；
7. **逐级端点时间校准**：用「低一级」周期K线校准本周期笔端点时间（`calibrateBiTimes`）——15分钟←3分钟、1小时←15分钟、4小时←1小时、日线←4小时；
8. **区间套强制对齐**：`alignBiToUpper(drawBis, prevBis, 上级间隔, rawBars)` 把本级别笔拐点对齐到紧邻上级笔拐点；第4参 `rawBars` 为本级原始K线，用于幽灵端点防御——上级极值在本级K线中不存在（跨周期数据源聚合差异）时跳过对齐，保留本级别真实极值。
9. **小周期绘制窗口过滤**：3分钟只绘制最近 15 天、15分钟只绘制最近 30 天（`DRAW_WINDOW_DAYS`），
   按 `最新K线时间 - 窗口天数×86400` 过滤掉更早的笔，避免小周期从起始日期到最新的全部笔堆叠导致图上过密；
   过滤同样作用于 `allBis` 落盘数据，`mark-buy-sell` 等只标记窗口内的笔。

### 3.4 绘制

- **清除**：切回源周期，按 title `CHAN_BI_<周期>` 只清除该周期自己画的笔（其他周期保留）；
- **创建周期选择**：有校准基准的周期（15/60/240/D）在**基准周期**（低一级）创建 shape——TradingView 的 polyline 只支持把点精确放在当前图表周期的 bar 边界上，校准后的端点时间（基准周期 bar 边界）若在源周期创建会被吸附到源周期 bar 边界导致校准失效；
- **数据覆盖检查**：绘制前 `ensureBarsCover` 确保图表数据覆盖最早笔的时间（否则早期笔端点被吸附到数据边缘形成无效笔）；
- 创建 `polyline`：起点 `{time: startTime, price: startPrice}`、终点 `{time: endTime, price: endPrice}`，`linecolor=resolutionColor(res)`、`linewidth=1`、`title=CHAN_BI_<周期>`，并 `applyIV` 设置可见范围。

### 3.5 落盘

所有周期绘制完成后写 `.cursor/cache/bis_<品种>.json`：

```json
{
  "symbol": "OANDA:XAUUSD",
  "from": "2026-06-30",
  "fromTs": 1782086400,
  "generatedAt": "...",
  "periods": { "D": [...], "240": [...], "60": [...], "15": [...], "3": [...] }
}
```

- 与图上实际绘制的笔完全一致（已 ATR 过滤、未完成笔延伸、跨周期端点校准）；
- `mark-buy-sell`、`mark-sr-flip`、`mark-entry` 均强制读取此文件。

## 4. 输出

| 项 | 说明 |
|----|------|
| 图上笔 | `polyline` 线段，按周期着色、只显示在本周期及低一级周期 |
| 笔数据缓存 | `.cursor/cache/bis_<品种>.json`（供买卖点/支阻位/进出场使用） |

## 5. 边界情况

| 场景 | 处理 |
|------|------|
| 未找到 TradingView 页面 | 报错退出 |
| 某周期无K线或切换失败 | 跳过该周期 |
| `--from` 之后无K线 | 跳过该周期 |
| 内层锚点范围K线不足 | 从外层笔列表从后往前扩展锚点 |
| 数据未覆盖起始日期 | `scrollToFirstBar` 加载完整历史，加载完滚回实时 |
| 切换周期后早期笔超数据范围 | 绘制前 `ensureBarsCover` 强制加载完整历史 |
| 3分钟/15分钟 从起始日期起笔过多 | 3分钟只绘制最近 15 天、15分钟只绘制最近 30 天（窗口过滤） |
| 3分钟覆盖起始日期加载超时 | 窗口内只需加载最近 15 天数据即通过覆盖检查，不再加载完整历史 |
| 最后无法等到目标周期 | 跳过该周期（避免用错误周期K线） |
