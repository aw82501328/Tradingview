# 交易计划（新）规格

> 状态：已确认的规则，尚未接入运行代码。当前回测和图表仍走旧计划（`SPEC.md` / `predictPlan`）。
> 时间口径：给人看的钟点为北京时间（UTC+8）。

每个周期只看当下最后一段。这段够笔之后，按下面两步出主计划。这段还不够笔时，主计划和另一侧都维持现在的买卖点结果。

## 1. 够笔定方向

最后一段是结构笔的末笔，形成中的也算。

- 已确认的笔：够笔。
- 形成中的段：合并块数达到 5（`enough` / `expectBiMinBars`）才够笔。

够笔之后：

- 上涨 → 计划做空。
- 下跌 → 计划做多。

## 2. 笔端点定买卖点

笔端点用当前最后一根已收盘 K，不等分型右邻。

- 上涨：这根 K 的高点。
- 下跌：这根 K 的低点。

前高、前低取这段之前最近几笔的端点高和端点低，包括这段所接的那一笔的起点。

做空：

- 端点高点高于这些前高里的最高点 → 一卖，策略「等待反弹后做2卖」。
- 一个前高都不过 → 类3卖，策略「等待反弹后的新卖点」。

做多：

- 端点低点低于这些前低里的最低点 → 一买。这段还在形成中，策略「等待低点附近的一买」；这段已经确认，策略「等待回调后做2买」。
- 一个前低都不破 → 类3买，策略「等待回调后的新买点」。

## 3. 计划怎么挂

够笔之后，上面这条是主计划，时间用那根收盘 K。反向锚点在这段够笔期间不再并行开单。

下一段反过来并且够笔，主计划就跟着翻：上涨够笔做空，下跌够笔做多。

## 本例

9月9日 05:00 起的 4 小时反弹，前高是 9月3日 21:00 的 4510.9。最后收盘 K 的高点约 4434，低于 4510.9。这段一够笔，主计划是类3卖、做空。弱类2买不再当主计划。

## 不在本规格里

- 不改买卖点识别（`chan_core` 的 1/2/3 类点怎么标）。
- 不改进出场闸门。策略句用现有文案，进场键不变。
- 弱二买、类2卖够笔作废等旧档位表保持原定义；够笔之后它们不再当主计划。
