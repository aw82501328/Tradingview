⑥ 结果明细表 过滤:

语义速查（生成 / 截断 / 合并 / 选取）
  • 生成·密集区 = 强互换(R2S/S2R：触及≥minTouch 且角色反转或突破) + 近期极值(RES/SUP：最近 N 笔端点、宽容差、无触及要求)
  • 生成·黄金分割 = 每方向最新非一类买卖点（引擎内现算）参照笔 × 比率；无已形成点走 pending 预期位
  • 生成·BOLL = 每周期最后 一根已收盘K线的 SMA±σ×倍数 三轨；中轨按现价侧定支撑/阻力；不足 length 根无位
  • 截断（仅密集区）= 超 maxPerPeriod 按评分留 Top N；评分 = 触及权重×触及 + 经过K线权重×经K线（候选集内 min-max 归一）；fib/boll 豁免
  • 合并 = 三类同池；价差 ≤ 合并容差×最小周期ATR 并条（价触及加权、level=最大来源周期、混合线去 fib/pending/boll 标记）
  • 选取上图 = 每显示周期池 = 级别 ≥ L 的合并线，距现价最近上/下各 sideCount 条，每条 ≤ 距离上限×线级别ATR
