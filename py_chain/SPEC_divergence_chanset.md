## Context：两个已复现案例暴露的同类错误

回测引擎（py_chain）在"60m/15m 检测周期 + 低级别当下背驰"上出现过两例与区间套原则冲突的信号归属：

**案例 A（2026-09-01 08:12，60m wait2Sell 做空）**：引擎报了 markRes=3（3m 微背驰 @4458.09），用户判定应为 markRes=15。
- 实测：60m 反弹笔（8-31 10:00→9-1 08:00 一带）内部按图表算法（JS chan-core）为 **15m 五笔结构**（10:45→19:15 上 / 19:15→21:45 下 / 21:45→04:00 上 / 04:00→07:15 下 / 07:15→08:15 上），末段 07:15→08:15 @4461.70 顶背驰成立（madeNew vs 段内 #3 @4455.93 ✓、近支阻 4462.54 ✓）。
- 引擎 py 的 15m 却把 21:45→04:00 上 + 04:00→07:15 下 + 07:15→08:15 上**吞并为单笔** 21:45→08:00 → 参照变成 8-31 顶 4464.23 → 15m 永不成立，只剩 3m 微段（07:21→08:12，参照 04:51→06:09 属 15m 下跌笔内部）先行触发。

**案例 B（2026-09-04 14:57→15:48 窗口）**：3m 末段上涨 14:57→15:48（4460.15→4490.90）与 15m 笔 14:45→15:45（同底 4460.16 同顶 4490.90）**同笔**——15m 笔内部 3m 只有这一笔（未展开）→ 区间套在 15m 层终止：15m 末段 vs 前一同向 15m 段（9-3 顶 4510.93）未创新高 → **不背驰、不应有任何信号**。引擎旧逻辑会拿 3m 末段 vs 3m 更早段（如 14:27/13:39 顶）判 3m——参照跨了 15m 笔边界。

诊断方法（复现用，已全部实测）：`py_chain` 引擎窗口回放 + wrapper 抓拍当下背驰评估快照；py/JS 双侧笔、分型逐层 diff；把 JS 15m 结构喂入引擎判定函数逐拍扫描验证 15m 候选成立时点（案例 A 于 08:45 后成立）。

## 确认的规则（区间套下沉判定，通用）

> P = 候选顶/底（背驰点），从检测周期 X 的"以 P 为终点的笔"开始逐级处理：

1. **规则 1（展开下沉）**：该级笔内部，若次一级别（15m/3m/…）存在 **≥3 笔完整结构**且末笔终点即 P → 判定下沉到次级别，重复；若次级别展开不足 3 笔（即与上级"同笔"或内部无独立子结构）→ **停止下沉，在本级判定**。
2. **规则 2（跨级禁止）**：候选背驰段的参照笔必须**与候选段同处于其所属上级笔内部**（"段内前一同向段"）；参照段若属于更早的上级笔（跨级比较），候选无效。
3. **规则 3（归属）**：markRes = 下沉停止的那一级；该级末段 vs 段内前一同向段执行 创新高/低 + MACD 背驰 + 近支阻 校验，通过才发信号。

**代入结果**：
- 案例 A：60m 笔内 15m 五笔展开 → 下沉 15m；15m 末段内部 3m 仅 1 笔 → 停 15m → 末段 vs #3（21:45→04:00@4455.93）→ **markRes=15 ✓**；3m 的 08:12 行不再产生。
- 案例 B：P 级笔（14:45→15:45）内部 3m 仅 1 笔 → 停 15m → 15m 末段 vs 9-3 顶 4510.93 未创新高 → **无信号 ✓**。

## 需要修复的两大块

### 块 1：py↔JS 笔结构对齐（前提，必须先行）
规则建立在正确笔结构上，而 py_chain 的 15m 笔在案例 A/B 都**吞并了图表（JS chan-core）能拆出的结构**（A：三段吞成一段；B：上午结构差异更大）。已证：同输入下 merge 与分型序列 **py==JS 完全一致**（案例 A 逐条核对），差异**全部在 buildBi/回溯/分型消费成笔环节**；3m 全一致、仅 15m（及可能 60m/240/D 边界）不一致。
- 修复动作：对 .cursor/skills/chan-core/scripts/chan_core.js（图表算法源，chan-bi/买卖点/中枢共用）与 py_chain/chan_core.py 的 buildBi 做**逐阶段 diff 定位吞并规则**（fractal 消费、回溯删除、端点候选、长影压平等近几轮 JS 迭代规则是否已回填 py），将差异规则回填 py，使引擎笔序列与图表落盘（chan-bi 输出）在 5 个周期上一致。
- 对齐后回归口径：引擎各周期笔列表 == JS chan_core 同输入重建（对拍脚本），再跑全量回测 stats 对比。

### 块 2：区间套下沉判定（mark_entry 三处 + 引擎次序）
- `py_chain/mark_entry.py`
  1. `realtimeLowerDiverge`（当下制，337-403）：候选（形成段创新高/低 + MACD + 近支阻）前先做**嵌套有效性检查**：找到以 P 为终点的可下沉链，确定"下沉停止级"，仅在该级产候选；3m 末段若与其上级 15m 笔同笔/未展开则 3m 不产候选。
  2. `lowerDiverge`（确认制，204-229）与 `findDivergePoints`（36-76）：同样加嵌套检查与"参照须在上级笔内部"约束；确认制"回退次新候选"逻辑（evaluateEntry 312-316）不得把高级别候选替换成跨级 3m/30S 微点。
  3. 30S 级别同规则（with_30s / ALL_RES；mark_entry.py 注释里已躺着一个 2026-09-04 13:39 的历史同类案例——作为回归用例）。

### 实现时需现场确认的口径（v1 先按下列默认，定稿前与用户过一遍）
- **上级笔未闭合时的处理**（当下制连续评估）：用"延伸中的上级笔 + 已闭合段"参与展开计数，末段计为未闭合段；若 P 所在的上级笔尚未闭合但内部已 ≥3 段次级别（含延伸段），可下沉；否则停在该级。（案例 A 08:12 当下：60m 笔未闭合、15m 已 5 段 → 下沉到 15m，15m 末段未闭合 → 停 15m 判当下背驰，信号时间取当下极值时刻。）
- **展开计数口径**：次级别"完整结构 ≥3 笔"= 以 P 为末笔终点的次级别笔序列中 ≥3 笔（段间不跨该级上级笔边界），含当下未闭合的延伸段计 1 笔。
- 下沉上限 = 检测周期 X（不越过 X 向上归属）；案例 A 由 60m 检测下沉到 15m，不再下探 3m。

## 实现结果（2026-09-08）

### 块1：笔结构对齐
- chan_core.py 回填 7 条 JS 规则：markWickBars（长影压平 + _topCand/_origLow 旁路）、
  _mergeStep 旁路传播、fractalAt 顶分型端点用影线价、fractalRangeClear 双向版
  （起点侧按方向 2 根 + 终点侧 3 根防反向吞没）、fragileMinimal 最小间隔脆弱笔例外、
  fixBiExtremes 底端点含中心 + _origLow 通道、引擎 _build_bis 补 nearDouble（≥60m）。
- **对拍（align_check，JS 侧 rebuild_bis.js 复用 chan_core.js）**：bars_all_tf.json
  6 周期（D/240/60/15/3/30S）逐笔 diff **0 差异**。
- **增量一致性（engine_consistency）**：引擎逐根推进状态 == batch(前缀) 全检查点通过——
  增量 wick 运行均值的早期漂移由 `_resync_bis`（每 RESYNC_EVERY=1000 根 fine bar 批量
  重同步，`run()` 收尾最终重同步）消除；`_rewind_res` 同步改为批量重建。
- **残余差异（文档化，不阻塞）**：图表管线专属步骤（lockedPivots/alignBiToUpper/ATR
  幅度过滤/calibrateBiTimes/绘制窗口）未移植——引擎 vs 图表落盘（bis_OANDA_XAUUSD.json）
  端点吻合率 240 93% / 60 93% / 15 97% / 3 90%（D 75%，仅 4 笔小样本）；案例窗口的
  15m 结构与图表逐笔一致（21:45→04:00@4455.93 / 07:15→08:15@4461.7 全对上）。

### 块2：区间套下沉判定
- `sinkChainRealtime` / `sinkChainConfirm`（mark_entry.py）：逐级下沉（levelsBelow 连续
  链不可跳级）、≥3 笔展开 + 末段终点即 P、**虚拟形成笔**桥接（X 末段端点已过、后续
  反向结构未确认——案例 A 的 60m 平台顶 4464.23 后近等后顶场景，与图表「近等双顶
  取后顶」最终结构结果等价）、规则 2 参照 containment（跨所属上级笔 → 候选无效）。
- realtimeLowerDiverge / lowerDiverge 只在停止级产候选；停止级可为 X 自身（新增
  S=X 信号类，realtime 实测出现 60 级 3 个）；去重键语义不变（验证通过）。
- **JS 图表侧同步移植（2026-09-08）**：`mark_entry.js` 移植确认制路径（`sinkChainConfirm`
  + `lowerDiverge` 下沉过滤 + `findDivergePoints` referStart，含虚拟形成笔），图表箭头
  归属口径与回测引擎一致；脚本重构为 `main()` + `module.exports` + `require.main`
  guard（与 mark_sr_flip.js 同模式，供 `mark_entry.test.js` 单测）；当下背驰模式仍为
  py 侧专属（SPEC §2.2 注明）。
